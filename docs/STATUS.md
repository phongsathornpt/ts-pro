# Implementation Status

## Target architecture correction

The target architecture is **TypeScript 7 for the compiler and Go only for the native runtime/native libraries**. The existing Go compiler under `cmd/` and `internal/` is transitional parity/reference code and must be retired as compile-time stages move into TypeScript 7. The handwritten runtime C implementation has been retired; `runtimego/` now owns the native runtime behind the stable C-compatible LLVM ABI.

## Historical compiler baseline

Commit `6bad298` is the historical native-compiler baseline used before the later dynamic-boundary and concurrency milestones. The current branch has progressed substantially beyond it.

```text
TypeScript 7.0.2
  -> diagnostics + checker/API snapshot
  -> TypeScript 7 AST/checker integration (current Go decoder is transitional)
  -> compiler semantic DTOs
  -> typed HIR + representation/range analysis
  -> MIR / SSA
  -> LLVM IR
  -> native linker + Go runtime ABI
  -> native executable
```

The generated executable does not embed Node.js or V8.

## Current coverage

- functions, recursion, direct calls, closures, escaping function values, classes/inheritance/dispatch, and initial generic specialization;
- arithmetic/comparisons plus proven integer arithmetic fast paths;
- mutable locals, top-level bindings, `if`, `while`, and `for` with SSA phi nodes;
- strings, specialized `number[]`, closed objects, shared heap ownership, and root-aware mark/sweep GC;
- tagged `JSValue` boundaries with primitive dynamic operators and checked unboxing;
- bounded Go scheduler, stackless tasks, work stealing, execution budgets, typed channels, timers, and bounded blocking-call isolation;
- stackless native async/await with typed result transfer, rejection propagation, `try`/`catch`/`finally`, task groups, cancellation, and inherited task-local context;
- deterministic Go runtime/object caching, generated `c-archive` ABI headers, native acceptance/differential tests, and performance reports;
- resilient long-lived TypeScript LSP workspaces.

## Runtime migration status

The runtime build now links the cached Go `c-archive` directly. Scheduler/task completion ownership, roots, task groups, context, channels, timers, blocking pool, strings, arrays, objects, JSValue, and heap/GC implementation live in `runtimego/`. Toolchain ABI tests compile against the header generated by `go build -buildmode=c-archive`; deleted `runtime/concurrency/*.c` and handwritten runtime headers are no longer part of the build or test path.

## Remaining sequencing rule

Scheduler/GC lifecycle integration is now in place: task-owned reference state and queued reference-channel values remain explicitly rooted, heap-threshold collection requests are deferred safely across active foreign root stacks, and scheduler return/wait/park/budget paths retry GC at safepoints. Allocator locality is now underway: small native allocations use worker-owned size-class spans with bounded reusable-span caching, zeroed slot reuse, and finalizer-safe recycling. The next step is bump-pointer nursery metadata and remote ownership transfer accounting before Green-Tea-style local mark-page queues.

Every milestone must pass `go test ./...`, native acceptance where applicable, and `git diff --check` before commit.
